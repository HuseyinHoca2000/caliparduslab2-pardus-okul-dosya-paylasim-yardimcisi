# ÇalıPardusLab2 Pardus Okul Dosya Paylaşım Yardımcısı

Bu proje, Pardus işletim sistemi kullanan eğitim kurumlarında okul içi dosya paylaşım alanlarına erişimi kolaylaştırmak amacıyla geliştirilmiş bir bağlantı yardımcısı prototipidir.

## Proje Amacı

Öğretmen ve öğrenciler, okul ağı üzerinde paylaşılan ders materyallerine, ortak klasörlere veya öğretmen paylaşım alanlarına erişmekte zorlanabilmektedir. Bu proje ile kullanıcıların okul dosya paylaşım bağlantılarına daha kolay ulaşmasını sağlayan sade bir yardımcı araç geliştirilmesi hedeflenmektedir.

## Hedefler

- Okul dosya paylaşım alanlarına erişimi kolaylaştırmak
- Öğrenci ve öğretmenler için sade yönlendirme sunmak
- Ağ paylaşımı kullanımını anlaşılır hale getirmek
- Pardus eğitim ortamlarına uygun yardımcı araç geliştirmek

## Temel Özellikler

- Paylaşım alanı menüsü
- Öğretmen klasörü bağlantı bilgisi
- Öğrenci klasörü bağlantı bilgisi
- Ortak ders materyali bağlantı bilgisi
- Terminal tabanlı sade kullanım
- Offline çalışma

## Hedef Kullanıcılar

- Öğrenciler
- Öğretmenler
- Eğitim kurumları
- Pardus kullanan okul ağları

## Kullanılan Teknolojiler

- Python 3

python3 src/okul_dosya_paylasim_yardimcisi.py
